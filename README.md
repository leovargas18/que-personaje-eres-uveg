# ¿Qué personaje eres? (Reto 5, U3 – Swift)

App SwiftUI (iOS 15+) con cuestionario de 5 preguntas.

- `Modelo.swift`: enum `Personaje`, structs `Pregunta`/`Opcion` y el arreglo de preguntas.
- `Cuestionario.swift`: lógica (arreglo, diccionario de puntos, ciclos for-in, guard).
- `ContentView.swift`: pantallas de pregunta y de resultado.
- `Pruebas/main.swift`: prueba de la lógica (se ejecuta en GitHub Actions).

Abrir `QuePersonajeEres.xcodeproj` en Xcode y ejecutar en un simulador o iPhone.
